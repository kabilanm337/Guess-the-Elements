# 🧪 Guess the Elements Web Game

An interactive, modern web-based quiz game designed to test knowledge of modern periodic table elements across the **s, p, d, and f-blocks** either by **Atomic Number** or **Atomic Symbol**.

Originally coded in Python during Class 11 as a console application, this project has been reimagined as a responsive web app with a clean UI built using HTML5, Tailwind CSS, and JavaScript.

## 🚀 Features
- **Block Selection:** Choose between s-block, p-block, d-block, and f-block elements.
- **Dual Modes:** Test yourself via Atomic Numbers or Atomic Symbols.
- **Real-Time Feedback:** Instant validation with round scores and final percentage calculations.
- **Responsive UI:** Built with Tailwind CSS for a seamless experience on desktop and mobile devices.

## 💻 Tech Stack
- **Frontend:** HTML5, Tailwind CSS, Vanilla JavaScript
- **Hosting:** Netlify / Vercel
